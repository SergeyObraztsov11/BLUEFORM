# Правила агента

Правила применяются к проекту BLUEFORM и сгруппированы по темам:

- [Git](rules/git.md): авторство, коммиты, ветки и отправка изменений.
- [Качество кода](rules/code-quality.md): имена, структура, ошибки и проверки.
- [Документация](rules/documentation.md): расположение документов и поддержание ссылок.

При добавлении темы создайте отдельный файл в `rules/` и добавьте ссылки в этот список и корневой `AGENTS.md`, указав, когда правило нужно читать. Не копируйте существующие правила в несколько файлов: обновляйте оригинал.
