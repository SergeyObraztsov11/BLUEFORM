# BLUEFORM — задачи

## Сделано для первой версии палитры

Взяли **каждый второй оттенок** из десяти на присланном референсе. Сейчас на сайте есть карточки ткани с фотографией фактуры, русским названием, образцом цвета, HEX-кодом и визуальной надписью «Смотреть оттенок»:

- 01 Dark Blue — **Тёмный синий** (`denim-midnight.webp`)
- 03 Indigo Blue — **Индиго** (`denim-indigo.webp`)
- 05 Medium Blue — **Средний синий** (`denim-coastal.webp`)
- 07 Sky Blue — **Небесный голубой** (`denim-sky.webp`)
- 09 Ice Blue — **Ледяной голубой** (`denim-icy.webp`)

Карточки листаются в Swiper. Надпись «Смотреть оттенок» пока не ведёт на страницу товара: пользователь попросил сначала оформить визуальную часть. HEX-коды взяты как ориентиры из текущих изображений; реальные цвета ткани нужно утвердить по физическим образцам.
